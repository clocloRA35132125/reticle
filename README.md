# Reticle

Site de présentation et de téléchargement de **Reticle**, un overlay de réticule pour Windows : un réticule personnalisé, au pixel près, par-dessus tous tes jeux.

- Import des codes de réticule CS2 et Valorant
- Éditeur en vue 3D et en vue 2D pixel par pixel
- Raccourci F8, démarrage avec Windows

## Télécharger

La dernière version de l'installateur est dans les [Releases](https://github.com/clocloRA35132125/reticle/releases/latest).

## Site

Site statique (HTML, CSS, JS) : GSAP + ScrollTrigger, Lenis et Three.js, servis depuis `vendor/`. Publié avec GitHub Pages.
